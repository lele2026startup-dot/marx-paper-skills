# 大学本科毕业论文格式一

内部标识 `undergraduate-01`，别名“本科格式一”“本科毕业论文规范版”。这是一套独立预置，保留原课程／学位通用格式和期刊格式。后续不同要求依次增加格式二、格式三，不能用新要求覆盖格式一，也不必每套新建一个 skill。

## 依据与适用边界

依据用户本地提供的三份原始 Word：校级论文工作要求、院级本科论文撰写要求、院级优秀论文评选标准。公共资源仅保存去身份化规则；不收录原始文件、原文件名、学校、学院、校徽、个人字段或可定位的来源路径。私有封面和身份信息只留在论文任务目录，不随模板同步或上传。

这是这些历史要求的预置实现，引用规范按其指定的 GB/T 7714—2015 核对；不把它称为所有高校的统一现行标准。优秀论文分数、重复率等属于评审条件，不能保证排好格式就满足。

## 固定规则

| 部分 | 格式一要求 |
|---|---|
| 顺序 | 封面→中文摘要→英文摘要→自动目录→前言／绪论→正文章节→结论→致谢→参考文献→可选附录／外文翻译 |
| 正文与摘要 | 宋体小四12磅，英文／数字选 Times New Roman；1.25倍行距，首行2字，段前后0，不对齐网格 |
| 摘要 | 中英文分页，各约300字；中英文题名位于摘要标题上方；关键词3—5个、两种语言对应、分号分隔、末尾无标点 |
| 标题与目录 | 摘要、前言、结论、参考文献等标题黑体小三15磅、居中、1.5倍行距、段后11磅；目录自动生成，条目宋体小四 |
| 章节 | 每章下一页分节；一级1、2、3，二级2.1，三级2.2.1；四／五级A.、a.并首行空2字；前言、结论、致谢、文献、附录不按本论章节编号 |
| 脚注 | 真页下注、圈码逐页重新编号、标记放句读后；注释与引用同页，脚注本身不得跨页，Word 实际分页验证 |
| 文献表 | 去重；宋体／Times New Roman五号10.5磅，左对齐、1.25倍行距、续行缩进、对齐网格 |
| 页码 | 封面无页码；摘要及目录罗马数字；前言至附录阿拉伯数字从1连续；页眉右侧Times New Roman五号 |
| 正式／盲审 | 正式稿有致谢；盲审排除作者、导师、学号、学校、院系及致谢，并检查文档部件和属性中的本地身份词 |

每处脚注仍须核实实际版本和定位。文献表不机械重复某次引文页码；原要求中“文献表不标页码”和期刊文章页码示例有出入，保留文章出版范围并在任务内核对，不能擅自批量删页码。

## 待核对项与当前取值

原始要求缺少完整官方封面样张、页边距／装订参数、各普通层级标题全部字号、续行缩进具体量；关键词与摘要间距同时出现“空一行”和“空二行”。当前使用中性封面、A4上下2.54厘米左右3.18厘米、普通一级黑体15磅／次级12磅、文献续行缩进2字、关键词间空一行，均属暂用值。英文题名与ABSTRACT间空一行。

参数保存在 `presets/undergraduate-01.json`。任务内确有补充要求时，通过本地 `meta.json` 的 `format_overrides` 覆盖 `page`、`heading`、`keywords`、`bibliography` 的已知字段，并记录依据；一次任务覆盖不自动改公共预置。封面用任务本地文件，交付前仍要视觉核对，不能声称中性封面就是官方样张。

## 输入与生成

正文 Markdown 从 `# 前言` 或 `# 绪论` 开始；各章用一级标题，章节内用二至五级标题。末尾依次包含 `# 结论`、`# 致谢`、`# 参考文献`；盲审可无致谢，已有致谢会整节排除。文献条目每条独立一段，以 `[1]` 等开头（必要时转义Markdown方括号）；脚注用Pandoc的 `[^n]` 定义。避免把正文题名、摘要、目录再写入正文输入。复杂表格、图注、公式须在任务内逐项检查，不按正文段落盲目改写。

在任务目录新建本地元信息；下面仅示意字段，不能把示例当论文内容：

```json
{
  "title": "论文中文题名",
  "english_title": "English Thesis Title",
  "abstract_zh": "本次真实中文摘要……",
  "abstract_en": "The corresponding abstract...",
  "keywords_zh": ["词一", "词二", "词三"],
  "keywords_en": ["term one", "term two", "term three"],
  "author": "仅本地填写",
  "advisor": "仅本地填写",
  "student_id": "仅本地填写",
  "institution": "仅本地填写",
  "faculty": "仅本地填写",
  "major": "仅本地填写",
  "submission_date": "仅本地填写"
}
```

使用可用的 Python，脚本路径解析为绝对路径：

```powershell
python scripts/build_docx.py body.md output.docx --preset undergraduate-01 --meta meta.json
python scripts/build_docx.py body.md blind.docx --preset undergraduate-01 --meta meta.json --blind
```

正式稿可加 `--cover-docx 本地封面.docx`（单节单页、已填写）替换中性封面，脚本只读原文件；暂不自动合并任务书、评语等多页材料。可加 `--pdf output.pdf` 导出PDF。更新目录、真实分页、圈码及同页检查需 Word 与 pywin32；缺项时报明依赖，或显式加 `--draft` 生成待验收稿，验收记录标记 `word_verified: false`，不得称为完成版。`--draft`不导出PDF、不载入封面；`--no-circle`不适用于本预置。

输出同名 `.report.json`，记录选用预置、待核对项、分页验收和内容条件。题名一般不超20字，正文一般不少于10000字（报告按正文段落非空白字符估算，不含标题、注释、致谢、文献及附录，正式字数用Word复核），参考文献不少于15篇，外文文献按研究需要通常不少于4篇。中英文摘要和外文文献需求由审核核对；脚本不补造材料来通过数量检查。身份词仍出现在正文或元数据时盲审生成失败，先在本地核对，不能自动删除合法引文；图片和未登记的身份线索仍须人工检查。标题含脚注时先把引注移入对应正文；同页超过20注须调整后验收。输出和记录默认不覆盖，获授权后 `--overwrite` 备份再替换。

## 后续积累新预置

1. 读取新原始要求，按编号新增匿名规则文件和参考说明，保留旧编号和默认行为。
2. 在总入口 `marx-paper/references/format-presets.json` 登记唯一ID、可说出的中文名、路由、指南和参数文件；一个预置的正式／盲审是变体，不另算一套。
3. 本地使用时，将新增预置安装到所用智能体的skills目录；向项目贡献时补充验证、更新安装清单，并按开发与贡献指南提交。公共文件不携带私人学校／学院身份；原始材料留在任务本地。
