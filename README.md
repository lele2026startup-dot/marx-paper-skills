# 马理论文章全流程 skill

面向马克思主义理论相关方向的理论研究与论文写作，提供选题、阅读、结构、素材、写作、审核与 Word 排版共 11 个 skill。可以按全流程推进，也可以只调用需要的环节。

## 开始使用

### 1. 下载并安装

在本页选择 **Code → Download ZIP**，解压后，将全部以 `marx-paper` 开头的 skill 文件夹安装到所用智能体的 skills 目录。每个文件夹里的 `SKILL.md`、脚本、参考资料和元数据应一并保留，不能只复制一个说明文件。建议整套安装，以便各模块共享交接规则和配套资源。

支持 `SKILL.md` 的智能体可按其安装方式加载；文件读取、联网检索、运行脚本和独立审核等能力取决于具体平台。本项目未逐一验证所有智能体的兼容性。

也可以使用仓库自带的安装工具。在解压后的目录打开终端，运行：

```powershell
python scripts/sync_skills.py --apply --backup-dir "../marx-paper-install-backups"
```

此工具默认安装到 `~/.codex/skills`。使用其他智能体时，将 `--target` 换成该平台实际要求的 skills 目录：

```powershell
python scripts/sync_skills.py --apply --target "你的智能体skills目录" --backup-dir "../marx-paper-install-backups"
```

目标目录应直接容纳 `marx-paper`、`marx-paper-topic` 等子文件夹。安装工具在覆盖已有文件前保留备份；遇到本地改动或未知文件时会停止提示。请先核对需要保留的内容，确认覆盖时再加 `--overwrite-installed`。

下载 ZIP 即可安装，无需使用 Git。识别或刷新 skill 的方式以所用智能体的说明为准。

### 2. 直接说明任务

安装后可以在对话中这样提出需求：

```text
用 marx-paper 帮我做一个马理论论文选题，先讨论研究切口。
```

```text
结构已经定了，只帮我整理这些参考论文中的引文和出处。
```

```text
用大学本科毕业论文格式一排版这篇稿子，生成盲审版。
```

也可以按平台支持的方式显式调用对应 skill。已有的结构、字数、引用和格式要求会继续沿用，缺少决定后续工作的必要信息时再补问。用户提供的具体模板和本次任务要求优先于预置默认值。

### 3. 按需准备依赖

选题、结构讨论和写作指导主要通过智能体完成；不使用本地排版脚本时，无需为了安装 skill 预先配置全部排版依赖。

配套脚本按 Python 3.12 及以上版本使用，常用依赖如下：

| 功能 | 依赖或条件 |
|---|---|
| 全文抓取 | Python 标准库及可访问的来源 |
| 素材 Word 与期刊 Word 生成 | `python-docx`、`lxml` |
| 课程／学位稿 Markdown 转 Word | 另需 pandoc |
| 自动逐页圈码、本科格式一完整分页验收 | Windows、Microsoft Word、`pywin32` |
| 来源核验和最终版面检查 | 本次任务的真实来源、目标模板及可用的文档查看／渲染工具 |

缺少依赖时，按当前环节说明处理。可生成待验收稿的功能会明确标记验收状态；其他文字处理程序的分页和域更新效果，需要在实际环境核对。

## 可选的三套排版格式

| 中文名称 | 使用场景 | 主要差异 |
|---|---|---|
| 课程／学位论文通用格式 | 课程论文、通用学位稿 | 单栏、宋体小四、默认1.5倍行距、圈码页下注 |
| 期刊／会议投稿格式 | 期刊投稿、会议征文 | 默认双栏、五号正文、真尾注和重复引用交叉引用 |
| **大学本科毕业论文格式一** | 本科毕业论文，正式／盲审 | 中英文摘要、自动目录、1.25倍行距、每章分节、页眉右侧分段页码 |

直接说“用大学本科毕业论文格式一”即可指定第三套。也可以提供自己的模板，在本次任务中调整。[完整格式清单](marx-paper/references/format-presets.json)登记名称与对应模块；[本科格式一说明](marx-paper-thesis-format/references/undergraduate-01.md)写清适用要求、暂用参数与输入方式。

后续可继续积累新的编号预置，已有格式保留。简单数字脚注是通用格式的一个选项。私人模板、学校／学院身份和个人元信息留在任务本地，不随公共预置发布。

## 工作流与模块

常见流程为 **选题 → 找文献 → 阅读（可选）→ 定结构 → 整理素材 → 写作 → 审核 → 排版**。指定全文检索与入库可直接使用 material；写作可选择快速式或逐段共写。

| Skill | 职责 |
|---|---|
| marx-paper | 总入口与单步路由 |
| marx-paper-topic | 选题、研究切口、候选拟题与检索准备 |
| marx-paper-material | 原著／讲话／政策／学术材料全文检索、TXT+Word 入库 |
| marx-paper-read | 阅读报告与用户思考记录，可选 |
| marx-paper-structure | 结构方案、标题与字数，版本化保存 |
| marx-paper-research | 引文、观点与数据素材，保存实际来源与核验状态 |
| marx-paper-quickwrite | 依据结构与素材快速写作 |
| marx-paper-cowrite | 逐段提问、收集想法、共写与过目 |
| marx-paper-review | 检查来源、论证、任务要求与语体，可用时独立审核 |
| marx-paper-thesis-format | 课程／学位论文脚注与 Word 排版 |
| marx-paper-journal-format | 期刊稿真尾注、重复引用域及默认双栏模板 |

期刊式初始框架约11500—12000字、3大×3小，具体按题目和本次要求调整。课程／学位稿默认圈码页下注和每页重编号；期刊稿默认真尾注与双栏。共写保留逐段提问、收想法和过目机制。已有任务要求优先，不要求每篇论文套用同一结构。

## 引文与输出约定

引用记录保留实际读取的来源、版本、定位和核验状态；未读原件时，保留转引或待核实信息。每处引用位置均保留，文献条目按来源去重。期刊重复引用通过 Word 交叉引用指向相应真尾注。

著录标准按目标学校／期刊指定版本执行；圈码、双栏和尾注属于具体模板或工作流选项。格式生成与样稿验证不替代真实来源核验和最终版面检查。共同交接规则见 [workflow-contract.md](marx-paper/references/workflow-contract.md)。

脚本默认保护已有输出。需要覆盖时，在已确认的授权范围内使用 `--overwrite`，备份旧文件后保存新结果。实证研究的数据和方法不由本系列包办。

## 获取更新

重新下载本仓库的最新版本，再安装到原来的 skills 目录即可。使用安装工具时，仍运行上述 `--apply` 命令；已有本地修改会触发保护，先核对并保留自己的修改，再决定是否覆盖。

希望核对安装结果时，可在本次下载的目录运行：

```powershell
python scripts/sync_skills.py --check
```

其他智能体使用与安装时相同的 `--target`。此检查只比较下载内容与指定安装目录，不需要 Git 或远端发布权限。
