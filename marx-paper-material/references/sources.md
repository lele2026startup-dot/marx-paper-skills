# 来源路由与抓取技术参考

本文档是检索入库的来源经验与踩坑清单。路由只是优先级建议，搜不到就换，用户给了 URL 就直接抓——**灵活是第一原则**。

## 1. 来源路由表

### 经典作家原著（马恩列毛等）

| 来源 | 说明 |
|---|---|
| **中文马克思主义文库 marxists.org**（首选） | 国际马克思主义档案馆中文部，经典著作全文最全。URL 模式：`marxists.org/chinese/<作者>/marxist.org-chinese-mao-YYYYMMDD.htm`（毛泽东按日期编号）；中央文件选集在 `marxists.org/chinese/reference-books/ccp-1921-1949/<卷>/<编号>.htm` |
| 维基文库 zh.wikisource.org | 公有领域全文，UTF-8 干净，适合交叉核对 |

查找技巧：用当前可用的网页搜索工具搜 `《标题》 全文 site:marxists.org` 或 `《标题》 marxists 作者 日期`。

### 党内历史文件（决议、决议案、会议文件）

- 首选 marxists.org 中央文件选集（`reference-books/ccp-1921-1949` 等）
- 搜查询词带文件全称或会议名称，如"中国共产党红军第四军第九次代表大会决议案 全文"
- 注意考证文件的**确切身份和日期**（同名文件可能有多份，如不同时期的"宣传工作决议案"），拿不准就跟用户确认指的是哪份

### 政策文件 / 领导人讲话（现当代）

官方网站优先，认准**文号**（如"中发〔2004〕16号""教高〔2020〕3号"）：

| 来源 | 适用 |
|---|---|
| 中国政府网 www.gov.cn | 国务院文件、规划纲要、政府工作报告 |
| 新华社 news.cn / 人民日报 people.com.cn | 中央文件全文发布、领导人讲话全文 |
| 教育部门户 moe.gov.cn | 教育类政策文件、思政课相关文件 |
| 共产党员网 12371.cn | 党内法规、党建文献 |
| 各部委官网 | 部门规章、通知 |

查询词模式：`《文件标题》 全文` + 文号或发文机关。政策文件常以"受权发布""全文发布"形式出现在新华社/人民日报。

### 学术文章 / 专著节选

- 知网 cnki.net、万方：多有访问限制，经常需要用户提供已下载的 PDF/CAJ
- 爱思想 aisixiang.com：学者文章、演讲、书摘，开放可读
- 期刊官网、学校官网的教师主页有时有开放全文
- 用户已给 PDF → 用 mineru-pdf2md 转文本后再整理

## 2. 编码规则（重点坑）

老中文网站（尤其 marxists.org）的编码很乱，这是历次抓取出错的最大来源：

1. 显式 --encoding 按严格指定编码解码，失败报错，不偷偷换编码。
2. 自动识别先看BOM、有效HTTP声明、HTML meta charset；无有效声明先严格UTF-8，再试GB18030/Big5。gb2312/GBK声明按其超集GB18030处理扩展字符。
3. ISO-8859-1/ASCII等泛化声明不作为中文网页的可靠线索。即使乱码签名为零，也要对照原页面首尾与篇幅。
4. 抓取使用标准库urllib，无需强制安装requests或指定搜索服务。取完整字节后再解码，不通过终端默认编码中转。
5. 输出为空或含明显损坏字符时拒绝发布。已存在文件默认保护；--overwrite在本次授权允许时使用并保留时间戳备份。

## 3. HTML 正文提取经验

**marxists.org 页面结构**（经典著作页通用）：
- 正文标题：`<p class='title1'>` 或 `<h1>`
- 正文段落：`<p>` 开头，常带全角空格缩进
- 脚注/注释区：文末 `<hr>` + "注释"字样之后——**提取到注释区之前截止**，不要把脚注和页尾导航收进来
- 日期行通常在标题后的括号里，如"（一九三○年五月）"

**通用提取策略**（其他站点）：
- 去 `<script>/<style>/<nav>/<header>/<footer>` 和侧栏
- `<h1>~<h6>` 转成 `##` 小节标记（排版脚本认 `##`）
- 实体解码（`&nbsp;` 等）、压缩连续空行
- 抽读首尾验证完整性

## 4. 路径与环境坑（Windows）

1. **Python 里的路径一律写 `E:/...` 或 `E:\...` 格式**。写 `/e/...` 会被 Python 解析成 `E:\e\...`，文件写到错误位置（真实事故：整批文件写丢到 `E:\e\` 下）。
2. bash（Git Bash）里 `/e/...` 没问题——两套工具注意区分。
3. 批量处理多文件夹时先 dry-run 列出将处理的文件清单，确认无误再真跑。

## 5. 其他经验

- **日期考证**：文件夹命名日期以原文标题下的成文日期为准（如"（一九三八年五月）"→ 1938-05）；政策文件用发布日期；只有年月就用 `YYYY-MM`，别硬造日子。
- **多篇批量**：一次会话处理多篇时，把抓取和排版都脚本化批量跑，不要逐篇手工——省 token 也不易错。
- **同一文献多版本**：选集版/单行本/文库版文字可能略有出入，优先选集版（权威校订），并在 TXT 来源说明里写清版本。
- **通稿 vs 全文**：讲话找不到全文就收通稿，在汇报和 SOT 里标明形态，别把通稿当全文用。
